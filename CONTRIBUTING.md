# Contributing to Kompi

Contributions are welcome. Bug reports, documentation fixes, and code changes all help.

For a small fix, feel free to open a pull request directly. If you're unsure whether a feature belongs in Kompi or how it should work, start a [discussion](https://github.com/karlis-vagalis/kompi/discussions) before you build it. Describe what you're trying to do and where Kompi falls short. You don't need a finished proposal.

When you open a pull request, explain what changed and how you checked it.
