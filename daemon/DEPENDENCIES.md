# Host dependencies

The Linux distribution includes Kompi under AGPL-3.0-only and upstream notices under `notices/`. Keep the matching tagged Kompi source and `rust-dependency-sources.tar.gz` with the binary. The archive contains the locked Cargo registry sources, including vendored native code. The local [iroh-tickets patch](../third-party/iroh-tickets/KOMPI.md) enables postcard's standard-library backend without its embedded heapless backend.

The worker and extension use separate Bun lockfiles. Install the worker's dependencies with `bun install --production --frozen-lockfile`; the release ships the lockfile rather than distributing a copy of `node_modules`. To check a dependency update, run `cargo audit` at the workspace root and `bun audit` in both `daemon/` and `pi-extension/`. Inspect target-specific paths with `cargo tree --locked --target x86_64-unknown-linux-gnu -i <crate>`. The lockfile includes Windows-only dependencies, including chrono via WMI. The Linux netlink build uses the unmaintained paste procedural macro at compile time.
