# Host dependencies

The Linux and Windows bundles include Kompi under AGPL-3.0-only and upstream notices in `notices.tar.gz`. The host's [Cargo.lock](../Cargo.lock) pins the Git revision of the [iroh-tickets fork](https://github.com/karlis-vagalis/iroh-tickets), which disables postcard's default features. Its MIT and Apache licenses are included in `notices.tar.gz`. Android instead uses the crates.io version selected by its [separate lockfile](../third-party/iroh-ffi/Cargo.lock). See [Corresponding source](../docs/releasing.md#corresponding-source) for release and redistribution requirements.

The worker and extension use separate Bun lockfiles. Packaging installs both frozen dependency sets at build time and bundles the worker and its Pi-loaded modules. Zod and TypeBox license texts accompany the bundles. Users do not install `node_modules` (except on v0.1.0). To check a dependency update, run `cargo audit` at the workspace root and `bun audit` in both `daemon/` and `pi-extension/`. Inspect target-specific paths with `cargo tree --locked --target x86_64-unknown-linux-gnu -i <crate>`. The lockfile includes Windows-only dependencies, including chrono via WMI. The Linux netlink build uses the unmaintained paste procedural macro at compile time.
